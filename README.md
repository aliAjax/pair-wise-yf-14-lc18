# hxyfront-62002 排练偏差复核台（剧场灯光 Cue 表）

在灯位与 Cue 表管理基础上扩展的**排练偏差复核台**：登记每次试运行的计划/实际触发时间、操作人与偏差原因，自动标记待复核并锁定相关灯具，导演处理结论 + 复演通过后才解锁。

## 复核规则

- 试运行登记：计划触发时间、实际触发时间（排练时钟 `HH:MM:SS`）、操作人、偏差原因。
- **偏差超过 8 秒**（绝对偏差 > 8s）或**操作人为空** → 自动标记「待复核」。
- 待复核 Cue **锁定亮度与焦点**：舞台图不可拖灯位、预览里亮度滑杆/焦点输入禁用、灯具筛选不可切换，三处统一显示锁定遮罩。
- 调整灯位前必须由**导演填写处理结论**（签名 + 结论 + 是否准予复演）。
- 导演准予复演后可登记「复演」；复演本身不再命中待复核规则（偏差 ≤ 8s 且操作人齐全）即通过，**只解除当前 Cue**。
- **历史偏差保留**：所有登记与结论不可删除；状态保存在浏览器 localStorage，**刷新后仍在**。

## 代码分层（状态计算 / 放行校验 / 界面分开维护）

| 模块 | 职责 |
| --- | --- |
| `src/lib/time.ts` | 时间码解析、偏差秒数、格式化（纯函数） |
| `src/lib/deviation.ts` | **状态计算层**：待复核评估、Cue 锁定状态派生、筛选可见性 |
| `src/lib/clearance.ts` | **放行校验层**：登记/复演/导演结论/亮度焦点调整门禁 |
| `src/lib/storage.ts` / `initialData.ts` | 本机持久化、初始演示数据 |
| `src/hooks/useConsoleStore.ts` | reducer 状态层，动作与派生状态的唯一组装点 |
| `src/components/*` | **界面层**：舞台图、场景预览、筛选、Cue 复核台、历史台账（只读派生状态，操作前问门禁） |

## 技术栈

React + Vite + TypeScript

npm install
