# hxyfront-62002 排练偏差复核台（剧场灯光 Cue 表）

在原有灯位 / Cue 表管理基础上扩展的**排练偏差复核台**，供灯光师与导演在排练期间使用。

> 原始需求：维护演出名称、灯具编号、通道号、色片、焦点位置、亮度预设和 Cue 触发顺序，提供舞台平面灯位图、Cue 列表、当前场景预览、灯具筛选和演出版本备注。

## 业务规则

- 每次试运行登记：计划触发时间、实际触发时间（mm:ss）、操作人、偏差原因，偏差秒数自动计算（实际 − 计划）。
- **偏差绝对值超过 8 秒，或操作人为空** → Cue 自动标记「待复核」。
- 待复核 Cue **锁定亮度与焦点**：舞台图上焦点不可拖动、详情面板滑杆禁用、场景预览显示锁定遮罩；调整灯位前必须由**导演填写处理结论（含导演姓名）**。
- 导演提交结论后进入「待复演」：此时允许按结论调整灯位，但界面仍保持锁定展示，必须登记复演。
- **复演通过只解除当前 Cue**（偏差 ≤ 8s 且有操作人）；复演仍超差则保留导演结论、继续锁定，可再次复演。
- **历史偏差永久保留**：所有试运行记录只追加不删除，放行后仍以 ● 标记；数据写入 `localStorage`，**刷新后仍在**。
- 舞台图、当前场景预览、筛选列表对未复核 Cue **统一显示锁定（🔒）**。

## 架构：状态计算 / 放行校验 / 界面分开维护

| 模块 | 职责 |
| --- | --- |
| `src/domain/status.ts` | 纯函数状态计算：时间码解析、偏差计算、`getCueStatus`、`isCueLocked` |
| `src/domain/release.ts` | 纯函数放行校验：能否调灯、能否提交结论、能否复演、能否放行 |
| `src/store.tsx` | 状态管理与 `localStorage` 持久化，写操作先调放行校验 |
| `src/components/*` | 界面：舞台图、场景预览、Cue 列表、复核工作台、筛选 / 备注 |
| `src/types.ts` / `src/seed.ts` | 数据模型 / 示例数据（含正常、待复核、待复演、已放行四种状态） |
| `src/domain/smoke.ts` | 状态机纯逻辑冒烟测试 |

## 本地运行

```bash
npm install
npm run dev                   # http://localhost:62002
npm run build                 # 生产构建
npx tsx src/domain/smoke.ts   # 领域逻辑测试
```

技术栈：React 19 + Vite + TypeScript。开发端口：62002。
